STL 批量减面工具 v1.8

运行环境
========
Windows 10/11 64 位。不需要安装 Python 或 MeshLab。

使用方法
========
1. 双击 STL_Batch_Simplifier_v1.8.exe。在顶部“文件夹”展开或收起目录设置。
2. 选择包含原始 STL 的输入文件夹。
3. 程序会自动建议一个“原文件夹名_simplified”输出文件夹，也可以自行修改。
4. 在底部“减面设置”选择“指定目标面数”或“指定保留比例”。同一面板可直接调整质量阈值、边界权重、平面权重等选项。
5. 点击顶部“批量处理”。完成后可直接点击“打开输出”。
6. 在左侧零件列表选择任一零件，在双视窗同步对比原始模型与简化结果。拖拽旋转，滚轮缩放，双击或点击“复位视角”复位。可拖动分隔线调整列表和视窗宽度。
7. 效果不满意时，选中一个零件，或用 Ctrl / Shift 多选，修改底部参数后点击“重做选中”。
8. 重新处理始终读取原始 STL，覆盖选中项的输出文件；无需勾选“覆盖输出目录中的同名文件”。其他零件不重新计算。
9. 点击列表标题处的“详细列”查看面数、减面率及使用参数。单选零件后可点击减面设置标题栏的“载入零件参数”继续调整。参数记录保留在本次程序会话中。
10. 想先看效果再保存时，选中一个或多个零件，修改参数，点击顶部“预览选中”。临时减面后右视窗显示“预览未应用”，不修改输出目录。
11. 不满意可继续修改参数并再次预览；满意后选择要保存的零件，点击“应用所选预览”保存当前已显示的临时结果。应用会覆盖对应输出 STL。
12. “放弃预览”可回到已有的输出模型；临时预览在关闭程序时清理。底部状态栏显示选中件数和待应用件数。

重要说明
========
- 保留比例 10% 表示最终保留原三角面数的约 10%，即减少约 90%。
- “目标面数”和“保留比例”为互斥模式，不会同时生效。
- 默认不会覆盖输出目录中的同名文件；需要覆盖时请勾选相应选项。
- 输出使用二进制 STL，保留原文件名；处理子文件夹时会保留目录结构。
- 支持中文输入/输出目录和中文 STL 文件名。
- STL 不保存面选择信息，因此“仅简化选中面”不适用于本批处理工具。
- “取消”会在当前正在处理的 STL 完成后停止后续文件。
- 零件列表显示原始面数、简化后面数、减少比例和处理状态。
- 原始/简化预览采用相同视角，任一侧旋转或缩放都会同步到另一侧。
- v1.4 预览改用 OpenGL 完整网格渲染，采用相同的灰色不透明材质和深度遮挡。

默认参数
========
保留比例：10%
质量阈值：0.3
保留网格边界：开启
边界权重：1.0000
保持法线：开启
保持拓扑：开启
最优顶点位置：开启
平面区域简化：开启
平面权重：0.001
按三角面质量加权简化：关闭
简化后自动清理：开启

算法
====
PyMeshLab / MeshLab Quadric Edge Collapse Decimation（二次误差边折叠减面）。
